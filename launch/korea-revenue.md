# 한국에서 돈 버는 구조 — 탄소 데이터/CBAM

트레이딩 알파는 없다(검증 완료). 대신 **강제 규제 = 확실한 수요**에서 번다.

## 핵심 통찰
- **CBAM(2026~)**: 한국 철강·알루미늄·시멘트·비료 EU 수출사는 탄소국경세를 **강제로** 낸다.
  중소 수출사 2만톤 기준 **누적 156억원**(계산기 실측치). 돈 낼 이유가 명확.
- **K-ETS**: 700+ 할당대상업체가 배출권을 사고팔아야 함 → 타이밍·전략 수요.
- **한국어 탄소 리서치 공백**: 제대로 된 한국어 탄소시장 분석이 거의 없음.

## 수익 깔때기 (Funnel)
```
① 무료 CBAM 계산기 (cbam.py 웹버전)   ← 리드마그넷
   "당신 회사 CBAM 비용 = 156억원" 충격
      ↓
② 유료 상세 리포트 (건당 ₩수백만)
   실측 배출계수 + 절감 시나리오 + 인증 가이드
      ↓
③ 월 구독 모니터링 SaaS (MRR)
   EUA 가격·CBAM 비용·K-ETS 대시보드 자동 업데이트
      ↓
④ 컨설팅/자문 (고마진)
   CBAM 대응 전략, K-ETS 매수 타이밍(계절성 분석)
```
+ 병행: **한국어 탄소시장 주간 뉴스레터**(리테일+실무자 구독)

## 타겟 고객 (한국)
- 철강·알루미늄·시멘트·비료 **중소 수출사** (대기업은 이미 컨설팅펌 씀 → 중소가 블루오션)
- 상사·무역회사 ESG/구매 담당
- 할당대상업체 배출권 관리 담당
- ESG 컨설팅펌 (화이트라벨 데이터 공급)

## 지금 있는 자산 (무자본으로 이미 만듦)
| 자산 | 역할 |
|---|---|
| `cbam.py` | CBAM 비용 계산기 — 리드마그넷 핵심 |
| `carbon_report.py`·`fair_value.py`·`seasonal.py` | 시장 분석 = 리포트/뉴스레터 콘텐츠 |
| `premium_box.py`·`kau.py` | K-ETS·프리미엄 모니터 |
| `dashboard.py` | 구독 SaaS 화면의 뼈대 |
| l1chain + carbon-token | 신뢰 후광 + 미래 정산/인증 레일 |

## 순서 (현실적)
1. **CBAM 계산기를 웹으로** (Vercel, 무료) → 링크 하나로 영업 시작
2. **한국어 뉴스레터 1호 발행** (이미 초안 있음) → 신뢰·리드
3. 관심 보인 곳에 **유료 리포트 제안** → 첫 매출
4. 반복 고객 → **월 구독**으로 전환

## 원칙
- 첫 돈은 **트레이딩이 아니라 "규제 대응 도구"**에서. 수요가 강제돼 있어 검증 불필요.
- 블록체인은 수익원이 아니라 **신뢰 후광 + 장기 정산 레일**.
- 무자본·상장불필요·한국어 강점 전부 활용.
